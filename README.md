# Локт Арогар — публичный профиль EU Forever

Подготовленный комплект, а не подтверждённая рабочая интеграция. Живой запрос
требует Blizzard Client ID и Client Secret. Маршруты Forever пока неофициально
документированы разработчиком клиента:
https://us.forums.blizzard.com/en/blizzard/t/60334

## Настройка

1. Создайте Public репозиторий `war4uk/wow-forever-armory`, включив Add a README.
2. Добавьте `sync.py` и `.github/workflows/sync.yml` из этого комплекта.
3. Settings → Secrets and variables → Actions → New repository secret:
   `CLIENT_ID` и `CLIENT_SECRET`. Значения берутся из Blizzard API Client.
   Не помещайте их в файлы, переменные репозитория, коммиты или чат.
4. Actions → Sync public character profile → Run workflow.
5. После успешного запуска откройте:
   https://raw.githubusercontent.com/war4uk/wow-forever-armory/main/data/character.json
   Проверьте имя, фамилию, ID, fetched_at, status и errors.

GitHub Actions запрашивает профиль ежедневно в 07:17 и 08:17 Asia/Tbilisi
(03:17 и 04:17 UTC). Второй запуск уменьшает риск устаревшего снимка к сводке
09:00. GitHub может задерживать задания; проверяйте fetched_at.
У неактивных публичных репозиториев GitHub может отключать расписание.

OAuth Client Credentials выдаёт токен приложения. Скрипт передаёт его только
в Authorization и не сохраняет в JSON или логах. Секреты доступны только шагу
запроса. Публикуются публичные ответы профиля, экипировки, талантов и профессий.
При недоступности основного профиля прежний JSON сохраняется, запуск завершается
ошибкой. При недоступности отдельных разделов status=partial, ошибки указаны
по разделам: отсутствие данных не означает отсутствие профессий или талантов.

## Ежедневная сводка

В существующую задачу ChatGPT следует добавить URL JSON выше только после
проверки первого реального ответа. Инструкция для сводки: прочитать JSON,
проверить fetched_at и status; если снимок старше 26 часов, не считать его
текущим. Использовать только разделы, реально присутствующие в data.
Не делать выводы об отсутствующих разделах. Если JSON недоступен, явно сообщить
об этом и не выдумывать уровень, экипировку или таланты.

Этот комплект не создаёт и не меняет задачу ChatGPT автоматически.
